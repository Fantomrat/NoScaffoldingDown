# No Scaffolding Down

**No Scaffolding Down** changes how scaffolding works.

You can only descend from scaffolding while looking down, preventing accidental falls while moving across scaffolding.

Normal sneaking behavior remains unchanged.

Modded scaffolding blocks extending vanilla's `ScaffoldingBlock` are also supported.
